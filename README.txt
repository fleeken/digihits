DIGIHITS PWA

Filer:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.svg
- icon-512.svg

För installation på mobil måste mappen publiceras via HTTPS.

När sidan öppnas:
Android: välj "Installera app" eller använd knappen i Digihits.
iPhone: Safari -> Dela -> Lägg till på hemskärmen.

Multiplayer och Spotify kräver internet även efter installation.
